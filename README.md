Student Performance Classification - Logistic Regression PipelineThis repository contains a complete machine learning pipeline built in Python using Scikit-Learn and Jupyter Notebooks. The project focuses on preprocessing academic records and training a binary classification model to predict high-achieving students using logistic regression.

🛠️ Practical WorkflowData Ingestion & Preprocessing: Loaded student_performance_dataset.csv using Pandas, dropped missing values across selected features, and engineered a binary target variable (High_Achiever) to classify students scoring 85 or above.Train-Test Split & Standardization: Partitioned the dataset into training (70%) and testing (30%) sets, and applied Scikit-Learn's StandardScaler ($z = \frac{x - \mu}{\sigma}$) to normalize continuous features like attendance and study hours for optimal model convergence.Model Training: Initialized and fitted a Logistic Regression model to mathematically map the relationship between the standardized features and the probability of a student being a high achiever.Model Evaluation: Assessed the model's classification performance on the unseen test set by calculating the Confusion Matrix, Precision, Recall, and the ROC-AUC score.Threshold Tuning & Interpretation: Tuned the classification decision boundary (e.g., shifting the threshold from $0.5$ to $0.7$) to optimize precision, and utilized the mathematical properties of the Sigmoid function ($\sigma(z) = \frac{1}{1 + e^{-z}}$) to explain how the model bounds outputs between $0$ and $1$.
