FIFA World Cup 2026 Player Performance - Linear Regression PipelineThis repository contains a complete machine learning pipeline built in Python using Scikit-Learn and Jupyter Notebooks. The project focuses on preprocessing match data and training a predictive model to analyze the physical output of players during the 2026 FIFA World Cup using simple linear regression.

🛠️ Practical WorkflowData Ingestion & Preprocessing: Loaded fifa_world_cup_2026_player_performance.csv using Pandas and dropped missing values across the selected feature (minutes_played) and target (distance_covered_km) columns to ensure clean training data.Train-Test Split: Partitioned the dataset into training (80%) and testing (20%) sets using train_test_split to allow for unbiased model evaluation on unseen data.Model Training: Initialized and fitted an Ordinary Least Squares (OLS) Linear Regression model using sklearn.linear_model to mathematically map the relationship between time on the pitch and distance run.Model Evaluation: Assessed the model's predictive accuracy on the test set by calculating Mean Absolute Error (MAE), Mean Squared Error (MSE), and the Coefficient of Determination ($R^2$).Visualization & Interpretation: Plotted the actual data points against the predicted regression line using Matplotlib and Seaborn, and extracted the slope coefficient and intercept to quantify the exact rate of distance covered per minute played.
